### What I'm building

| Project | What it is |
|---|---|
| **[tailreach](https://github.com/TanmayDoesAI/tailreach)** | Control a Mac from any browser over your own Tailscale network, or turn a spare laptop, tablet or phone into a second monitor. Hardware H.264 over WebRTC tuned for mobile links; every request is checked against the visitor's Tailscale identity. `brew install` via [homebrew-tailreach](https://github.com/TanmayDoesAI/homebrew-tailreach). |
| **[Tool Selection Lab](https://github.com/TanmayDoesAI/tool-selection-lab)** | How should an agent with many tools find the right one? Show it everything, route by category, retrieve a shortlist, or let it search. 100 tools, 329 tasks, 9 strategies, plus a kit to run the same comparison on your own agent. ([write-up](https://blog.tanmaylabs.me/ai/agents/2026/10/12/100-tools-one-agent-search-or-see-everything/)) |
| **[LocalMind](https://localmind.tanmaylabs.me)** | A self-hosted workspace for AI chat, research, documents and artifacts, for teams that need control over models, knowledge access and deployment. |
| **[Hakoniwa](https://3d.tanmaylabs.me)** | A miniature Japanese valley under glass. Shape its weather with clouds, snow and time of day, then step inside and walk around. All in the browser. |
| **[Siri for tanmaylabs.me](https://tanmaylabs.me/play/)** | The assistant on my site: answers from the page, streams replies, takes voice questions. Every message passes a jailbreak classifier and a written safety policy, checked by a 62-case red-team suite. |
| **Home server** | One laptop serving my site, blog and ~20 other apps: power modes that stop heavy apps on battery and restore them on reboot, apps that sleep when idle and wake on first visit, Cloudflare edge rules, encrypted off-site backups. |

Also: **mcp-gateway**, a self-hosted gateway that exposes APIs as MCP tools with OAuth, scoped access and identity federation (private).
